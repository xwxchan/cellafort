검객 대전

여섯 문파의 검객이 종이 인형처럼 겨루는 2D 무협 대전. 설치 없이 여기서 바로 하고, 방 코드 하나로 친구와 붙습니다.

처음 한 번은 약 20 MB를 내려받습니다. 키보드나 게임패드가 필요해요.

게임 메뉴는 방향키로 고르고 Enter로 정합니다. 뒤로 가기는 Esc.

공중에서 점프를 두 번 더 쓸 수 있고, 강공격을 꾹 누르면 상단세로 기를 모았다가 떼는 방향으로 일격을 날립니다. 전체 기술표는 게임 중 Esc.

친구와 대전하기

  1. ONLINE을 고르고 검객을 정합니다.
  2. 한 사람이 CREATE ROOM을 누르면 화면에 방 코드가 뜹니다.
  3. 그 코드를 메신저로 친구에게 보냅니다.
  4. 친구는 JOIN WITH CODE에 코드를 넣고 Enter. 바로 대전이 시작됩니다.

아는 사람이 없으면 QUICK MATCH로 기다리는 아무 상대와 붙을 수 있어요. 이 사이트와 PC판끼리도 대전됩니다.

검객

  • 무명검객낭인중도를 쓰는 균형형. 발을 구를 때마다 충격파가 인다.
  • 매화검객화산파연속 공격형. 세 번째 칼부터 매화 꽃잎이 터진다.
  • 태극검객무당파반격형. 막는 순간 흘려 내고 되받아친다.
  • 제왕검객남궁세가파괴형. 막혀도 검압으로 밀어낸다.
  • 환영검객종남파속도형. 지나간 자리에 환영이 남아 다시 찌른다.
  • 혈영검객마교폭주형. 체력이 바닥날수록 빨라진다.
