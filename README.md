# SHROUD 웹사이트

무협 검객 대전 SHROUD의 웹 버전을 GitHub Pages로 서비스하는 저장소입니다.

- 이 폴더의 내용은 Unity에서 **SHROUD → Build Website (WebGL)** 로 만든 `Builds/SHROUD_site/` 를 그대로 복사한 것입니다.
- `.nojekyll` 은 GitHub Pages가 파일을 가공하지 않고 그대로 내보내게 합니다.
- 게임 소스는 Unity 프로젝트(cellafort)에 있습니다.

GitHub Pages 설정: 저장소 Settings → Pages → Source "Deploy from a branch" → Branch `main`, 폴더 `/ (root)` → Save.

사이트 버전: v0.9.10 (2026-11-06)
